# Dungeon Crawler Carl

A neon pop-art theme inspired by the *Dungeon Crawler Carl* book series by
Matt Dinniman — vibrant neon colors on pure black, echoing the Penguin Random
House / Will Staehle cover art and the sardonic in-world "System" interface.

## Palette
- **Accent:** hot magenta `#ff2d78`
- **Supporting neons:** electric cyan `#00d9ff`, acid yellow `#ffe600`
- **Epic purple:** `#c04dff`
- **Surfaces:** pure black `#000000`
- Light mode uses deepened versions of the same neons for contrast on off-white.

## Fonts
- **Sans / body:** Chakra Petch (400/500/600/700) — chunky sci-fi display sans
- **Mono / code:** Space Mono (400)

Both fonts are SIL Open Font License 1.1 (see `LICENSE.txt`).

## Install
Settings → Display → Install theme → point at this folder.
